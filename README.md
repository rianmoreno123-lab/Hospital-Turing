Padronização de nomes de constantes
As constantes deverão seguir um padrão de nomenclatura para serem facilmente identificadas no código. O grupo adotará o formato camelCase (letras minúsculas nas iniciais e letras maiúsculas nas palavras compostas subsequentes, sem o uso de caracteres separadores como underlines ou hífens).
Exemplos:maxTentativasLogin = 3
statusItemDisponivel = "disponivel"
statusItemRetirado = "retirado"
